User guide

Using Verso

Verso mixes video live. You place clips in a grid, play one clip per layer, and the layers stack on the GPU into one image: the output. This guide goes from installation to a full show.

Install

Download the package for your system from the latest release.

Windows

  1. Unzip Verso-x.y.z-windows-x64.zip anywhere (Desktop, C:\Tools, a USB stick).
  2. Run verso.exe.

FFmpeg is included next to verso.exe. Keep the effects, presets and scripts folders next to the executable: Verso loads its effects and MilkDrop presets from there.

Windows SmartScreen may warn that the app is unrecognised, because it is not signed. Click More info › Run anyway.

macOS

  1. Open Verso-x.y.z-macos-universal.dmg and drag Verso.app to Applications.
  2. The first time, right-click Verso.app › Open, then confirm. The app is not notarized by Apple, so a double-click alone is refused.
  3. Install FFmpeg for video: brew install ffmpeg (with Homebrew).

If macOS still says the app is damaged, run xattr -dr com.apple.quarantine /Applications/Verso.app in Terminal. Allow microphone access when asked: audio-reactive effects and MilkDrop listen to the audio input.

Linux

Fedora and other RPM distributions:

sudo dnf install ./verso-x.y.z-1.x86_64.rpm
sudo dnf install ffmpeg-free   # or ffmpeg from RPM Fusion for every codec

Ubuntu and Debian:

sudo apt install ./verso_x.y.z_amd64.deb

Portable archive, with FFmpeg included:

tar xzf Verso-x.y.z-linux-x86_64.tar.gz
./Verso-x.y.z-linux-x86_64/verso

Verso needs a Vulkan driver (Mesa on AMD and Intel, the proprietary driver on NVIDIA) and runs on X11 and Wayland.

From source

git clone https://github.com/elisalien/verso
cd verso
cargo run --release -p verso-app

Needs stable Rust. On Linux, install the ALSA, udev, xkbcommon, Wayland and X11 development packages first.

The interface

  • Menu bar: Composition, Edit, Layer, Column, Output, Window, then MIDI Learn, Control…, Scripts… and TAP with the tempo. The frame rate and the composition name sit on the right.
  • Clips: the grid. One row per layer, one column per scene. The Composition row on top holds the master fader.
  • Crossfader: under the grid, mixes layers assigned to side A or B.
  • Properties: Composition, Group, Layer and Clip panels show the settings and effects of the selection.
  • Preview, Cues and Output monitors.
  • Browser: Sources, MilkDrop, Effects, Files and Online tabs. Drag from here onto the grid.
  • Status bar: the last message. Click it for the history of messages and errors.

Every panel docks: drag a tab to another group or to an edge to split, drag separators to resize, right-click a tab › Undock to open it in its own window. The Window menu reopens panels, adds more Properties panels, resets the layout or saves yours as the default. Window › Interface Colors… changes the theme.

Clips and columns

A clip is a source in a slot of the grid. Each layer plays at most one clip at a time.

  • Click a cell to play its clip on that layer. Clicking an empty cell clears the layer. Clicking the clip already playing restarts it.
  • Click a column header, or press 1–9, to launch the whole column on every layer at once.
  • Esc clears every layer.
  • Hover a clip, layer header or column header: the Preview monitor shows the clip, the layer alone, or what the column would output, without touching the output.
  • Right-click a cell to change its source or clear it. The small number on a cell counts how many times it was launched (right-click › Reset Counter).

Add or remove layers and columns from the Layer and Column menus, or right-click a header › Delete. Every structural edit can be undone with Ctrl+Z.

Layers and mixing

Layers stack from the bottom (Layer 1) to the top. Each layer header has:

ControlKeyEffect
XXEject: stop the clip on this layer
BBBypass: hide the layer without stopping it
SSSolo: show only this layer
A / BA / BAssign the layer to a side of the crossfader
Faderdouble-click resetsLayer opacity

The blend mode (Alpha, Add, Multiply, Screen, Lighten, Darken, Difference) is set in the Layer panel. Add and Screen brighten, Multiply darkens, Difference inverts where layers overlap. The Composition fader is the master opacity of the whole output.

Sources

Generators

Browser › Sources lists built-in generators (Plasma, Gradient, Stripes, Rings, Solid Color) and generator shaders. Drag one onto a cell, or select a cell and double-click the source. Hover a source to preview it; Thumbnails shows them as a grid of live images.

Video and images

Drop image or video files from your file manager onto a cell: they fill that slot and the following ones. Browser › Files › Open Folder… lists a folder's media to drag in. Every codec FFmpeg reads plays: H.264, H.265, ProRes, HAP and Resolume DXV3 among others. For many layers of HD video, prefer HAP or DXV: they decode much faster than H.264. The Clip panel has the transport (play, pause, position).

Online shaders

Browser › Online searches the ISF library and ShaderToy and imports shaders. Generators appear under Sources, filters under Effects. ShaderToy needs your free API key. ShaderToy shaders are usually licensed CC BY-NC-SA: use the commercial-use filter and check the shader page before a paid show.

MilkDrop

Verso runs MilkDrop presets natively, reacting to the audio input (set it in Control…). 147 preset families ship with Verso, sorted by category in Browser › MilkDrop. Remixes of one preset are grouped into one source: pick the variant in the Clip panel.

  • Blend: changing the preset of a clip, or launching another MilkDrop clip on the same layer, blends like MilkDrop does: the new preset takes over the image left by the previous one.
  • Input: feed another layer into the preset, as its image texture and mixed into its feedback (Input Mix). Set that layer's opacity to 0 to use it only as an input.
  • Your own presets: put Butterchurn .json files in the milkdrop folder of Verso's user folder (see Files). Raw .milk files are not supported yet.

A fresh preset often starts black and fills in after a second or two. Without audio input, many presets stay dark: check the audio device first.

Effects

Effects process the image at four levels: a clip (travels with the clip), a layer (applies to every clip on it), a group, or the composition (the final output).

  • Drag an effect from Browser › Effects onto a clip, a layer header or the Composition header.
  • Or select the target and use + Add Effect in its Properties panel.
  • Effects run in order, top to bottom. Each parameter can be modulated (see Control).

Write your own effects in WGSL (Verso format) or ISF (.fs). Verso loads them from the effects folder next to the program, and from any folder picked in Browser › Effects › Load Folder…. Examples: effects/wave.wgsl and effects/scanlines.fs.

Groups and transitions

Ctrl/Shift-click adjacent layer headers, then Ctrl+G to group them. A group has its own opacity, blend mode, bypass and effects, applied to its layers mixed together. Groups nest; Ctrl+Shift+G ungroups. The ▸/▾ button collapses a group; its ▶ buttons launch a column inside that group only.

A layer's Transition (Layer panel) crossfades from one clip to the next over the given duration instead of cutting.

MIDI, OSC and audio

MIDI learn

  1. Press L or click MIDI Learn.
  2. Click a control in the interface (a fader, a cell, a button).
  3. Move or press the MIDI control. Repeat for other controls, then leave learn mode.

Control… lists MIDI inputs and mappings, the OSC port, the audio input and the modulators.

Modulation and tempo

Right-click any fader or effect parameter to add an LFO or an audio modulation (level of a frequency band). LFOs are synced to the tempo: tap it with T or the TAP button.

Cue list

The cue list (Window › Cues) plays a written show: theatre, dance, a set with fixed moments.

  1. Set up a look: launch clips, place faders.
  2. Click Record. The cue stores the clip playing and the opacity of every layer, the master and the crossfader.
  3. Repeat for each moment. Update rewrites the selected cue.
  4. During the show, press GO or Space: the next cue plays with its fade (clips crossfade, levels glide). Back returns to the previous one.

Each cue either waits for Go or follows on by itself after some seconds or beats. Moving a fader by hand stops a fade in progress.

Output and mapping

Output window

F2 opens the output window. Move it to the projector or second screen and double-click it for full screen.

Advanced Output

Output › Advanced Output… maps the composition onto several screens and surfaces:

  • Screens: one per display (full screen on that monitor) or an NDI source.
  • Slices: in Input Selection, choose which part of the composition each slice takes; in Output Transformation, place it on the screen. Drag slices, corners, polygon points and warp grid points.
  • Masks: draw polygons by clicking, or import them from SVG.
  • Soft edge blends overlapping projectors. Test patterns, Identify and Highlight Selection help align on site.
  • Import and export Advanced Output presets in the Resolume Arena .xml format, or drop one on Verso.

NDI

Output › NDI® Output publishes the output on the network, for OBS, a streaming PC or another media server. It needs the NDI runtime (installed with NDI Tools).

Lua scripts

Scripts… opens the editor. A script defines frame(t) (every frame) and/or beat(n) (every beat), and drives Verso with the OSC addresses:

-- Pump the master on the bass, launch the next column every bar.
function frame(t)
  verso.set("/master", 0.6 + 0.4 * t.audio.bass)
end

function beat(n)
  if n % 4 == 0 then
    verso.trigger("/column/" .. (n // 4 % verso.columns() + 1) .. "/launch")
  end
end

t carries the time, the musical time in beats (t.beats) and the audio analysis (t.audio.bass…). Ctrl+Enter applies. Scripts are saved in the composition and run sandboxed: no file or system access, endless loops are stopped. verso.get(address) reads a value. This example ships as scripts/beat-chase.lua.

Files and saving

Ctrl+N / O / S create, open and save .verso compositions (Ctrl+Shift+S: save as). A * in the title means unsaved changes; Verso asks before losing them. A composition also stores its panel layout.

A modified composition is copied every two minutes to name.verso.bak next to its file (or Untitled.verso.bak in the user folder). Saving removes the copy.

SystemUser folder
Windows%APPDATA%\Verso
macOS~/Library/Application Support/Verso
Linux~/.config/verso

It holds the layout, the log (verso.log), imported shaders (shaders/) and your MilkDrop presets (milkdrop/).

Agent control (MCP)

Verso can run a Model Context Protocol server so an AI agent such as Claude Code reads the composition, drives it and gets rendered images. It is off unless asked for at launch, listens on 127.0.0.1 only and refuses destructive actions without confirmation.

verso --mcp 7400
claude mcp add --transport http verso http://127.0.0.1:7400/mcp

Troubleshooting

Videos do not play

The status bar says "FFmpeg not found". Install FFmpeg (see Install) or set the VERSO_FFMPEG and VERSO_FFPROBE variables to the two programs.

No effects or MilkDrop presets

The effects and presets folders must sit next to the executable. Do not move verso.exe out of its folder: create a shortcut instead.

MilkDrop stays dark

Pick the right audio input in Control… and play some sound.

The window does not open, or the image is black

Update the graphics driver. On Linux, install the Vulkan driver (mesa-vulkan-drivers on Fedora). The log in the user folder (verso.log) says which GPU was picked and why it failed.

Report a bug

Open an issue on GitHub with your system, GPU, what you did, and verso.log (Window › Messages shows its path).
