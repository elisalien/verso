EN
--
Start Verso:
  Windows  double-click verso.exe
  Linux    ./verso   (or install the .deb / .rpm package)
  macOS    open Verso.app (first time: right-click > Open)

Keep the effects, presets and scripts folders next to the executable:
Verso loads its bundled effects and MilkDrop presets from there.

Video playback needs FFmpeg. The Windows and Linux archives include
ffmpeg and ffprobe next to verso. On macOS: brew install ffmpeg.

User guide: https://elisalien.github.io/verso/guide.html
Report a bug: https://github.com/elisalien/verso/issues
