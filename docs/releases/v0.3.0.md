**Verso is free and open source VJ software for Windows, macOS and Linux.**
Website and user guide: https://elisalien.github.io/verso/ · [Version française plus bas](#français)

This is the first public release. Verso is young: please [report bugs](https://github.com/elisalien/verso/issues), with `verso.log` (Window › Messages shows its path).

## Download

| System | Package | Notes |
|---|---|---|
| Windows 10/11 x64 | `Verso-0.3.0-windows-x64.zip` | Portable, FFmpeg included. Unzip and run `verso.exe` |
| macOS 11+ (Apple Silicon and Intel) | `Verso-0.3.0-macos-universal.dmg` | First launch: right-click › Open. `brew install ffmpeg` for video |
| Fedora, openSUSE | `verso-0.3.0-1.x86_64.rpm` | `sudo dnf install ./verso-0.3.0-1.x86_64.rpm` |
| Ubuntu 22.04+, Debian 12+ | `verso_0.3.0_amd64.deb` | `sudo apt install ./verso_0.3.0_amd64.deb` |
| Other Linux x86_64 | `Verso-0.3.0-linux-x86_64.tar.gz` | Portable, FFmpeg included |

Check downloads against `SHA256SUMS.txt`. The Windows and macOS builds are not signed: Windows SmartScreen and macOS Gatekeeper ask for confirmation on first launch.

## What's in it

- **Clip grid**: layers × columns, column launch with keys 1–9, solo, bypass, eject, A/B crossfader, layer groups (nested), clip transitions, launch counters, hover previews of clips, layers and columns.
- **Sources**: generators, images, video through FFmpeg (H.264, H.265, ProRes, HAP, Resolume DXV3), video transport, generator shaders.
- **MilkDrop**: native engine, 147 preset families, MilkDrop blending between presets and between clips on a layer, video input from another layer.
- **Effects**: WGSL and ISF chains on clips, layers, groups and the composition; online ISF and ShaderToy browser.
- **Output**: output window, Advanced Output with screens, slices, polygon masks (SVG import), warp grids, soft edge blending, test patterns, Identify; Arena `.xml` preset import and export; NDI output.
- **Show control**: cue list with Go, fades and follow-on; MIDI learn; OSC (Verso addresses and the `/composition/…` scheme); audio analysis; tap tempo; LFO and audio modulation; sandboxed Lua scripts.
- **Workflow**: dockable and floating panels, layouts saved with compositions, undo/redo, autosave every two minutes, log file, optional title bar, interface colours.
- **MCP server** (opt-in, `--mcp`): lets an agent read and drive the composition and capture rendered images.

## Known limitations

- Raw `.milk` MilkDrop files are not loaded yet (Butterchurn `.json` only).
- The interface is in English.
- macOS builds are made by CI and less tested than Windows and Linux.

### Au programme

- **Grille de clips** : couches × colonnes, lancement de colonne avec 1–9, solo, bypass, éjection, crossfader A/B, groupes de couches imbriqués, transitions, compteurs de lancement, aperçus au survol.
- **Sources** : générateurs, images, vidéo via FFmpeg (H.264, H.265, ProRes, HAP, Resolume DXV3), transport vidéo, shaders générateurs.
- **MilkDrop** : moteur natif, 147 familles de presets, fondu MilkDrop entre presets et entre clips d'une couche, entrée vidéo depuis une autre couche.
- **Effets** : chaînes WGSL et ISF sur clips, couches, groupes et composition ; navigateur ISF et ShaderToy en ligne.
- **Sortie** : fenêtre de sortie, Advanced Output avec écrans, slices, masques polygonaux (import SVG), grilles de déformation, soft edge, mires, Identify ; import et export des presets Arena `.xml` ; sortie NDI.
- **Conduite** : liste de cues avec Go, fondus et enchaînements ; MIDI learn ; OSC (adresses Verso et schéma `/composition/…`) ; analyse audio ; tap tempo ; modulation LFO et audio ; scripts Lua isolés.
- **Confort** : panneaux ancrables et flottants, disposition enregistrée avec la composition, annuler/rétablir, sauvegarde automatique toutes les deux minutes, journal, barre de titre optionnelle, couleurs d'interface.
- **Serveur MCP** (sur demande, `--mcp`) : un agent peut lire et piloter la composition et capturer les images rendues.

### Limites connues

- Les fichiers MilkDrop `.milk` bruts ne sont pas encore chargés (`.json` Butterchurn seulement).
- L'interface est en anglais.
- Les versions macOS sont produites par la CI et moins testées que Windows et Linux.
